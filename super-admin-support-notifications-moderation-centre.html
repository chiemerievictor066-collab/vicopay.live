Admin response & case update

This preview stores updates only in the current browser page. It does not send a message to a customer.

Safety and production boundary: This is a standalone UI prototype with fictional records. It does not connect to customer accounts, messaging, push notifications, moderation tools or the database. Reports are allegations until reviewed; use evidence-based decisions, preserve relevant records, restrict sensitive case access and provide an appeal path. For real deployments, enforce role-based permissions, MFA, audit every action, protect private user data, and never expose internal notes in customer-facing replies.
